# Manim Skill 작업 흐름

사용자가 자연어로 명령을 내리면 아래 순서로 작업이 진행된다.

## 전체 흐름

```
사용자: "cutileGPT 소스코드를 분석해서 동영상 만들어줘"
                    │
                    ▼
┌─────────────────────────────────────────┐
│  1. 소스코드 분석 (탐색 에이전트)         │
│     - model_tile.py, kernels/*.py 전부 읽음 │
│     - 텐서 shape, 연산 흐름, 알고리즘 파악   │
│     - 타일 크기, 메모리 패턴 등 세부사항 정리  │
└─────────────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────┐
│  2. 씬 구성 기획                         │
│     - 어떤 순서로 보여줄지 결정            │
│     - 각 씬의 시각적 표현 방식 설계         │
│     - manim_skill의 베스트 프랙티스 참고     │
└─────────────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────┐
│  3. Manim Python 코드 작성               │
│     - Scene 클래스 작성                   │
│     - 텐서 그리드, 화살표, 수식, 그래프 등   │
└─────────────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────┐
│  4. Manim CLI로 렌더링                   │
│     - source .venv/bin/activate          │
│     - manim -qm -a 파일.py               │
│     - 각 씬이 개별 .mp4로 출력             │
└─────────────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────┐
│  5. FFmpeg로 합본                        │
│     - 개별 mp4를 순서대로 연결             │
│     - 최종 영상 파일 생성                  │
└─────────────────────────────────────────┘
                    │
                    ▼
              사용자에게 결과 전달
```

## 역할 분담

| 단계 | 담당 | 설명 |
|------|------|------|
| 1. 분석 | Claude (LLM) | 소스코드를 읽고 구조와 로직을 파악 |
| 2. 기획 | Claude (LLM) | 씬 구성, 시각적 표현 방식 설계 |
| 3. 코드 작성 | Claude (LLM) | Manim Python 코드 생성 |
| 4. 렌더링 | manim CLI | `manim -qm -a 파일.py` 실행 |
| 5. 합본 | ffmpeg | 개별 씬을 하나의 영상으로 연결 |

## 참고

- 렌더링 에러 발생 시 코드를 수정하고 4단계부터 재시도
- 사용자 피드백이 있으면 3단계부터 수정
- manim_skill 베스트 프랙티스: `external/manim_skill/skills/manimce-best-practices/`
- 가상환경: `/home/hwoo_joo/thirdparty/manim_skill/.venv/`
